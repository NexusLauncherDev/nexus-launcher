# Changelog

## v2.1.0-beta.1 — Open Beta — 2026-10-25

- First public beta release of Nexus Launcher and Nexus Setup 2.0.
- Includes instance management, Modrinth content browsing, Studio, Cinematic Launch, Mod Intelligence, Crash Investigator, and Companion surfaces.
- Setup supports choosing an install folder, current-user installation, update of an existing installation, file-integrity checks, and recovery after an interrupted operation.
- The installer is unsigned. See the release notes and README for verification instructions and limitations.
