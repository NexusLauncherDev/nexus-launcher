# Feedback and contributions

This repository distributes the closed-source Nexus Launcher binary and public product documentation. Pull requests that change launcher or installer source code are not part of the beta workflow.

Please use GitHub Issues to report reproducible problems or suggest product improvements. Include the launcher version, Windows build, Minecraft version, loader, expected behavior, actual behavior, and reproduction steps. Redact private paths, user names, and account data from logs.

Do not upload game files, private account data, copyrighted mod packs, or security exploit details.
