# Security policy

Nexus Launcher is in open beta. Security reports are welcome.

Please do not publish credentials, account tokens, email addresses, or full unredacted logs in an issue. Remove personal information and private file paths before attaching diagnostic files.

For a suspected vulnerability, use GitHub's private vulnerability reporting on this repository if the Security tab offers it. If private reporting is unavailable, open a minimal issue asking for a private contact channel; do not include exploit details or sensitive logs in the public issue.

Supported release: the latest beta release. Fixes and disclosure timing are handled case by case during the beta.
